Sleke Migrate

Move everything to your new phone.

Contacts, photos, videos, and files go straight from this phone to the new one over Wi-Fi. Nothing is uploaded anywhere.

Download for Android

Latest release for Android 9 and newer.

Install this on the old phone, the one you are moving away from. The new phone shows a pairing code inside the Sleke setup wizard.

Install it

  1. Open the downloaded file

    Tap sleke-migrate.apk in your notifications or in Downloads.

  2. Allow this one install

    Android asks before installing from a browser. Tap Settings, turn on Allow from this source, then go back.

  3. Tap Install, then open the app

    It walks you through the rest.

How the move works

  1. Start setup on the new phone

    Choose to bring data from another phone. It shows a pairing code.

  2. Scan the code with this phone

    The two phones lock onto each other. No account, no sign-in.

  3. Pick what to send

    Contacts, whole albums, or folders. Keep both phones awake and on the same Wi-Fi while it sends.

Private by design

Your data travels phone to phone over your own Wi-Fi. Before anything is sent, the connection is pinned to the exact device that showed the code, so nothing can be sent to a stranger's phone. There is no server in between and nothing to delete afterwards.
